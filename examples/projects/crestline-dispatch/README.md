# Crestline Dispatch demonstration

Fictional company and synthetic evidence. Sanitized historical reports are provided for coursework review. All source emails, sender/contact identifiers, message/thread identifiers, original project/run IDs, credentials, authorization policies, runtime state and original DOCX metadata are excluded.

The evidence summary is intentionally narrower than the original scenario. Reports retain their historical observations and may describe missing evidence or earlier workflow snapshots. The execution summary shows the accepted completed run; narrative status tables may refer to an earlier snapshot. No security controls were implemented by publishing these files.

These are reference archives, not live project folders. Do not feed them to the launcher as genuine customer requests. The Word report is regenerated from the sanitized Markdown and is not independently visually approved.
