# Sanitized demo assessment projects

Four fictional assessment archives, published with operator approval for coursework demonstration. Each contains a sanitized brief, a synthetic evidence summary, seven report artifacts, a regenerated Word report and a minimal execution summary.

- [Cedar Lantern](cedar-lantern/README.md)
- [Northwind Orchard](northwind-orchard/README.md)
- [Atlas Bridge](atlas-bridge/README.md)
- [Crestline Dispatch](crestline-dispatch/README.md)

Original operational data under `agency/projects` remains excluded and unchanged. These archives are not a certification, real-client assessment or compliance claim. No complete original email, inbox metadata, contact information or operational authorization is included.
