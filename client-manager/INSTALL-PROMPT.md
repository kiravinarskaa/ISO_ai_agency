# Client Manager setup guide

This workspace already defines the Client Manager. Before using it, confirm the project root and project ID supplied by the operator, ensure the project's `client-input`, `working`, and `outputs` directories are present, and confirm local file and Node access. Do not search public websites for client facts or create evidence.

Read `CONTRACT.md`, `ROLE.md`, `SCHEDULE.md`, and the selected routine instructions. Run the local guard before scheduled work. The Client Manager prepares local artifacts and communication drafts only. The agency provides certification-readiness preparation only; it does not certify clients.
