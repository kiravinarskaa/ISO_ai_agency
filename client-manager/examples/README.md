# Client Manager run examples

These examples show the six active routine IDs and the run record shape. Client information is deliberately omitted. Project-specific artifacts are created under `D:\AgentOps\agency\projects\<project-id>`, not in the employee kit.

| Routine | Owned artifact |
|---|---|
| `client-intake` | `working/client-brief.json` |
| `client-input-review` | `working/missing-information.md` |
| `client-clarification-draft` | `working/client-clarification-draft.md` |
| `project-handoff` | `working/project-handoff.json` |
| `client-progress-update` | `working/client-progress-update-draft.md` |
| `final-readiness-delivery` | `outputs/final-client-delivery-draft.md` |

The `.cmd.example` files under `run/` show the guard entry point. Every draft remains local and unsent. The agency provides certification-readiness preparation only.
