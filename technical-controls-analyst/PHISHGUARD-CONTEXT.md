# PhishGuard AI

## Product
PhishGuard AI is a B2B cybersecurity micro-SaaS.

## Purpose
The service helps users analyze suspicious emails for phishing and social-engineering indicators.

## Main AI Feature
A user provides an email.

The system analyzes it and returns structured information including:

- urgency
- threat
- credential request
- financial request
- sensitive data request
- possible impersonation
- social-engineering techniques
- preliminary risk: low, medium, or high
- explanation

## Target Users
Small businesses, teams, and employees who regularly handle business email.

## Current Stage
University prototype.

## Business Model
B2B micro-SaaS.

Possible future model:
- limited free tier
- paid business subscription

## Current Product Status
The email-analysis prototype already exists.

The current implementation uses:
- Python

- structured JSON output
